Press Play

Romlin picks the right emulator for each console and sets it up for you. Games and BIOS files come from your RomM server, and games you download play offline.

  • Snes9x
  • Genesis Plus GX
  • Mupen64Plus-Next
  • Beetle PSX HW
  • PCSX2
  • RPCS3
  • Dolphin
  • xemu
  • Flycast
  • mGBA
  • melonDS DS
  • PPSSPP
  • Many more

Most run as libretro cores. ARMSX2 and FAKE-08, for PICO-8, come from Romlin's own builds. xemu and RPCS3 run as standalone apps.

RomM 5.4

Send a game from RomM

Choose Install on device in RomM, pick Romlin, and the game starts downloading straight away. A card shows its progress, with a Play button when it's ready.

  • Install on device
  • Notifications in the sidebar
  • Save sync that knows each device's version

Romlin works with RomM 5.0 or newer. These need RomM 5.4.

Looks

A look for every console

Each console starts with the screen it was played on. Change it any time from the game menu.

RetroAchievements

Earn achievements as you play

Sign in with your RetroAchievements account. You get popups and leaderboards, and hardcore mode once RetroAchievements approves Romlin. Each game's page shows what you earned.

Save states

Save anywhere

Each save state has a picture of the moment. Saves sync with RomM, so you can continue on another computer. How save sync works

Two screens for DS

Also

  • A native app, written in Rust.
  • Every game runs in its own sandbox.
  • Interface sizes of 1x, 1.5x or 2x.
  • Gamepads, light guns, mice and keyboards.
  • A game menu on the Guide button or Esc.
  • If a save changed in two places, you choose which one to keep.
  • The whole app works with a controller.
  • Picks up where you left off.
  • Find a console by name, and clear every filter in one click.
  • Tells you when a new version is out.

Download Romlin

Free and open source. You need a RomM server, version 5.0 or newer, or 5.4 to send games to Romlin. Romlin doesn't include any games or BIOS files. You need your own.
